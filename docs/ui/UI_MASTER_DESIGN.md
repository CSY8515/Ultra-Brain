# Ultra Brain UI Master Design

Version: 0.94.0

Ultra Brain is the official user environment for understanding and entering governed systems. The concept-art scene itself is the navigation surface: the central World Tree and sun-like sphere represent Ultra Brain, while each visible Seed represents one registered, reachable child system. v0.8 renders only the registered OS Ecosystem entry.

The first viewport prioritizes the Ultra Brain concept-art world and one unambiguous UI Studio entry. v0.94 keeps the default view quiet, preserves Official Theme language, and adds a real User Custom Canvas Editor for drawing, assets, components, layers, locks, preview, and rollback without replacing the world model with dashboard cards.

UI Studio changes are local to Ultra Brain presentation preferences. Theme propagation is an explicit compatibility contract with lock and override states; it never transfers repository, runtime, or ownership authority to a child system.

Authority remains `User > Ultra Brain > Meta OS > OS Ecosystem > Project > Module > Feature`. UI propagation does not transfer repository or runtime ownership.
