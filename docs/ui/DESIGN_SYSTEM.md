# Global Design System

The official language uses natural dark materials, restrained antique-gold accents, semantic HTML labels, and a world-first composition. Tokens cover color, typography, spacing, shape, shadow, motion, background, surface, component state, and accessibility.

Typography uses local system families. Gold communicates active paths while green communicates healthy state; neither color is the only signal. Every interactive object has hover, keyboard focus, active, reduced-motion, and touch behavior.
