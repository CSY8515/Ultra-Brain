# World Architecture

World entities expose identity, parent, status, health, version, connection, permission, destination, and contract. A visual object may be interactive only when backed by a registered navigation entry.

The v0.8 route is `User > Ultra Brain > OS Ecosystem`. The Ultra Brain sphere is the selected current location. The single lower Seed is OS Ecosystem and opens the independent application in a new tab. Unregistered future worlds are not rendered as placeholders.
