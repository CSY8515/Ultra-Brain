# Ultra Brain v0.94 — User Custom UI & Canvas Editor

Release date: 2026-08-06

v0.94 extends the v0.93 Official UI Foundation with a real User Custom UI workflow inside UI Studio. Official world themes and their concept-art language remain intact; custom work is stored as a separate local User Custom Theme or UI revision.

## Included

- Full-screen User Custom Canvas Editor with Desktop, Mobile, and Full screen preview modes.
- Direct drawing tools: pen, brush, eraser, line, rectangle, circle, triangle, text, fill, and gradient.
- Color, size, opacity, zoom, Grid, Snap, Safe Area, undo, redo, and clear controls.
- PNG, JPG, JPEG, WEBP, and SVG image import with a visible canvas preview.
- Built-in component placement for Ultra Brain, OS Ecosystem, UI Studio, Workspace, Project, Search, and Settings.
- Layer visibility, layer lock, selection, drag positioning, reorder, duplicate, and delete controls.
- User Custom Theme registry stored locally with base-theme and preview metadata.
- Save/apply/rollback integration with existing UI Studio revisions and hierarchy propagation.
- Position, size, background, layout, color, texture, lighting, component, and layer locks.
- Production world view kept quiet: only the top-left UI Studio entry is visible by default.

## Compatibility

v0.94 preserves the v0.93 layout editor, official theme registry, preview, rollback, Override, Lock, and hierarchy propagation contracts. Lower-level repositories remain consumers of the Ultra Brain UI payload and do not receive independent UI Studios.
