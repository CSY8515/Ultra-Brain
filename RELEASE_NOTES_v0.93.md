# Ultra Brain v0.93 Layout & Custom UI

## Scope

v0.93 completes the production UI pass on top of the v0.92 Theme System and
adds a governed Layout Editor for Ultra Brain UI Studio.

## Included

- Quiet world-first default screen with only Ultra Brain, OS Ecosystem, and the UI Studio entry visible.
- Korean-first practical UI copy while retaining English product and world names.
- Official theme detail labels, Korean presets, and locked adjustment feedback.
- Drag & drop layout editing with position, scale, visibility, pinning, grouping, and alignment controls.
- Layout, background, component, color, texture, and lighting locks.
- Before/After preview and rollback points that include theme, layout, and imported background state.
- Existing hierarchy propagation, Override, Lock, and child editor boundaries preserved.

## Compatibility

No Living OS, Universal Learning Engine, OS Ecosystem, Project, Module, or Feature
source was changed. UI editing remains exclusive to Ultra Brain UI Studio.
