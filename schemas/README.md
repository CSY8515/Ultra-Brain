# Ultra Brain Schemas

The schemas in this directory are JSON Schema Draft 2020-12 contracts for v0.1 foundation data.

- `registry.schema.json` defines registry containers and common indexed entities.
- `interface.schema.json` defines a publishable interface description.
- `contract.schema.json` defines explicit behavioral obligations.
- `ecosystem_integration.schema.json` defines the v0.7 OS Ecosystem management,
  dependency, independence, operational-flow, and navigation manifest.
- `decision.schema.json` defines a durable governance decision.
- `release.schema.json` defines a release evidence record.

Schemas define structure only. Passing schema validation does not approve an entity, permit execution, or satisfy governance and release gates by itself.
