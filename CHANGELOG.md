# Changelog

All notable changes to Ultra Brain are recorded in this file. The project uses
milestone versions that correspond to the roadmap and Git release tags.

## [v0.5] - 2026-08-01

### Added

- Collaboration & Connectivity Core Meta OS architecture, MASTER Design,
  immutable records, validation, interface, contract, schemas, and registry.
- Governed registered connectors, API request budgets, caller-resolved
  credential references, bounded JSON/JSONL/CSV import/export, deterministic
  snapshot synchronization, idempotency, and sanitized lifecycle evidence.
- Explicit external-AI, repository-write, communication, cross-platform, and
  ecosystem connector boundaries with separate permissions.

### Preserved

- v0.1 Foundation, v0.2 Safety, v0.3 Enhancement, and v0.4 Automation
  implementation and authority.
- Personal Secretary remains scope-only and unmodified.

### Boundary

- No stored secrets, provider SDK, daemon, polling, background sync, UI/UX,
  Streamlit, Core Capability, OS Ecosystem, Living OS, ULE, Ultra Brain-
  exclusive capability, or deployment.

## [v0.4] - 2026-08-01

### Added

- Automation Core Meta OS architecture, MASTER Design, immutable records,
  validation, interface, contract, schemas, and registry.
- Caller-driven workflows, schedules, triggers, routines, registered local
  action execution, typed decisions, DAG pipelines, bounded batches, and local
  notifications.
- Safety-referenced grants, allowlists, budgets, idempotency, bounded retries,
  cancellation, reverse compensation, sanitized audit events, validator, and
  automatic tests.

### Preserved

- v0.1 Foundation, v0.2 Safety Core, and v0.3 Enhancement Core implementation
  and authority.
- Collaboration & Connectivity and Personal Secretary remain scope-only and
  unmodified.

### Boundary

- No UI/UX, Streamlit, background service, external connectivity, Core
  Capability, OS Ecosystem, Living OS, ULE, Ultra Brain-exclusive capability,
  or deployment.

## [v0.3] - 2026-08-01

### Added

- Enhancement Core Meta OS architecture, MASTER Design, public records, strict
  input validation, interface, contract, schemas, and registry.
- Dependency-free analytics, bounded learning, pattern analysis, knowledge
  candidates, optimization, draft rules, prediction, insight, and advisory
  decision support.
- Enhancement validator and automatic functional, adversarial, provenance, and
  protected-scope regression tests.

### Preserved

- v0.1 Foundation and v0.2 Safety Core implementation and authority.
- Automation, Collaboration & Connectivity, and Personal Secretary remain
  scope-only and unmodified.

### Boundary

- No UI/UX, Streamlit, automation, external connectivity, Core Capability,
  OS Ecosystem, Living OS, ULE, or Ultra Brain-exclusive implementation.

## [v0.2] - 2026-08-01

### Added

- Safety Core Meta OS architecture and MASTER Design.
- Executable validation, integrity, monitoring, risk, safety logging, audit,
  backup, recovery, execution-safety, and incident-management controls.
- Approved Safety registry, interface, contract, policy, and data schemas.
- Dependency-free Safety validator and adversarial automatic test suite.

### Preserved

- v0.1 Foundation authority, architecture, governance, rules, policies,
  standards, repository strategy, and workspace protection.
- All other Core Meta OS domains remain scope-only and unmodified.

### Boundary

- No UI/UX, Streamlit, automation, external connectivity, Core Capability,
  OS Ecosystem, Living OS, ULE, or Ultra Brain-exclusive implementation.

## [v0.1] - 2026-07-31

### Added

- Ultra Brain Foundation and the v0.1-to-v1.0 roadmap.
- Constitution and governance baseline.
- Rules, policies, and standards baseline.
- MASTER Architecture.
- Registry Architecture.
- Validation Framework and release evidence gates.
- Release Framework and repository strategy.
- Workspace protection requirements.
- Scope-only initialization of the five Core Meta OS domains.

### Boundary

- No runtime capability, user interface, external dependency, or v0.2-and-later
  feature is implemented in v0.1.
