# Ultra Brain v0.96 — UI Builder Evolution

v0.96 turns UI Studio into a production-oriented UI Builder while preserving the v0.95 concept-art world engine and hierarchy ownership rules.

## Included

- Builder-first canvas with frames, containers, text, buttons, cards, panels, widgets, navigation, icons, shapes and drawings.
- Exact X/Y/width/height, rotation, opacity, multi-select, drag placement, grouping, z-order, visibility, lock, duplicate, delete, copy/paste and keyboard undo/redo.
- Desktop, tablet, mobile and full-screen preview modes with grid, guides, safe area, snap and component state previews.
- Asset Library with multi-image import, search, preview and canvas insertion; official concept art remains immutable.
- Component state preview for Default, Hover, Focus, Active, Selected, Disabled, Loading, Error and Success.
- Templates for Main, Dashboard, Workspace and Minimal starting layouts.
- UI package metadata for world asset, layout preset, component skin, responsive targets and save revision policy.
- Every save creates a revision; draft, applied, rollback and emergency restore flows are available in UI Studio.
- Rollback creates a new rollback revision and keeps hierarchy propagation, Lock and Override behavior unchanged.

## Boundaries

UI editing remains owned by Ultra Brain UI Studio. OS Ecosystem, Living OS, Universal Learning Engine, Project, Module and Feature receive unlocked settings through the existing propagation contract; lower systems do not gain independent editors. The default screen remains quiet and keeps only essential Ultra Brain navigation and the UI Studio entry.
