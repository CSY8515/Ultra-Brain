# Changelog

## [0.61.0] - 2026-08-03

### Recovered

- Personal Secretary Architecture Audit and Operational Reporting Architecture.
- Canonical operational-report and advisory-brief port, contract, and schemas.
- Ultra Brain, Core Meta OS, Registry, Validation, Release, OS Ecosystem,
  project, and database status domains.
- Living OS and Universal Learning Engine Database Manager report mappings.
- Recommendation, approval request, optional Automation handoff, outcome
  reporting, and failure/recovery/rollback support boundaries.

### Preserved

- The v0.6 Python runtime and its 0.6.0 assistance interface and contract are
  unchanged.
- No UI, runtime, source project, database, or OS Ecosystem modification.

## [0.6.0] - 2026-08-01

### Added

- Consent-aware Daily Briefing, Weekly Review, and Monthly Review.
- Reminder, recommendation, priority, decision, personal assistance, context,
  and scheduling support as bounded non-executing services.
- Immutable records, strict validation, interface, contract, schemas, registry,
  validator, and automatic tests.

### Boundary

- No personal-data persistence, profile inference, external I/O, autonomous
  action, notification delivery, calendar write, UI/UX, Streamlit, or deployment.
