# Changelog

## [0.6.0] - 2026-08-01

### Added

- Consent-aware Daily Briefing, Weekly Review, and Monthly Review.
- Reminder, recommendation, priority, decision, personal assistance, context,
  and scheduling support as bounded non-executing services.
- Immutable records, strict validation, interface, contract, schemas, registry,
  validator, and automatic tests.

### Boundary

- No personal-data persistence, profile inference, external I/O, autonomous
  action, notification delivery, calendar write, UI/UX, Streamlit, or deployment.
