# Ultra Brain v0.95 — Advanced Theme & Visual World Engine

Release date: 2026-08-06

## Summary

v0.95 turns the official Theme System into a Visual World Engine. Selecting a
theme now changes the interpretation of the existing Ultra Brain concept art as
a complete world: atmosphere, layout language, surface texture, lighting,
shadow, typography, component treatment, and motion are resolved together.

## Included

- Registry-driven official themes: Universe, Ecosystem, Galaxy, Ocean,
  Grassland, Lava, Minimal, Paper, Archive, plus the Official sun world.
- Theme Browser with concept-art world previews.
- Theme Detail preview showing each world's world description, layout, motion,
  and source asset.
- World-specific atmosphere layers: orbital space, nebula, canopy, tide,
  wind, molten flow, paper drift, and archive rings.
- Existing brightness, contrast, saturation, hue, lighting, shadow, glow,
  texture, blur, and transparency controls remain available without changing
  the selected world's illustration language.
- Korean-first operational labels in UI Studio; product names remain English.
- Existing User Custom Canvas, preview, rollback, hierarchy propagation,
  Override, and Lock behavior preserved.

## Boundaries

Only Ultra Brain UI Studio owns editing. OS Ecosystem, Living OS, Universal
Learning Engine, Project, Module, and Feature receive the governed payload but
remain independently owned and directly uneditable.
