# Ultra Brain v0.97 — Professional UI Studio & Creator Experience

v0.97 corrects the v0.96 UI Studio experience and makes the creator surface usable from first action to professional layout work.

## Corrections

- Official themes continue to apply the approved concept-art world package: world image, atmosphere, composition and component treatment change together rather than only changing a color.
- Practical controls use Korean-first wording; product names and professional vocabulary remain available in the advanced and expert toolboxes.
- Ecosystem hover is scoped to the OS Ecosystem seed and no longer changes or reveals the whole screen.
- The default view stays quiet with only Ultra Brain, OS Ecosystem and UI Studio entry points.

## Professional UI Studio

- Collapsible toolboxes for beginner, intermediate, advanced, expert, touch-pen and mouse workflows.
- Beginner actions: new screen, image/background/icon/photo/AI image import, add button/text, move, resize, delete, undo, save and apply.
- Drawing tools: pen, pencil, brush, marker, airbrush, eraser, fill, shapes, text, stabilizer, pressure-aware input, opacity, zoom, rotation and canvas pan.
- Mouse tools: precision move, snap, smart guide, multi-select, align, distribute, duplicate, context menu, drag and copy/paste.
- UI Builder remains the primary surface for components, layout, assets, templates and responsive preview.
- Revision history, Undo, Redo, Rollback, Compare-ready preview and emergency restore remain available.

## Boundaries

Only Ultra Brain UI Studio is edited. OS Ecosystem, Living OS, Universal Learning Engine, Project, Module and Feature keep their existing ownership and receive unlocked propagation only.
